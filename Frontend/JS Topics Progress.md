### **JavaScript Learning Checklist**

#### Level 1: Foundations (Beginner)

**Basics of JavaScript**
- [x] Variables (`var`, `let`, `const`)
- [x] Data Types (Number, String, Boolean, Null, Undefined, Symbol, BigInt)
- [x] Type conversion (implicit vs explicit)
- [x] Operators (arithmetic, comparison, logical)

**Control Flow**
- [x] Conditional statements (`if`, `else if`, `switch`)
- [x] Loops (`for`, `while`, `do...while`, `for...of`, `for...in`)

**Functions**
- [x] Functions (declaration, expression, arrow functions, default params)
- [x] Closures, Variable Shadowing

#### Level 2: Working with Data (Core)

**Strings**
- [x] Strings & Template Literals
- [x] String methods (`slice`, `substring`, `replace`, `split`, etc.)

**Arrays**
- [x] Arrays basics (indexing, iterating, multidimensional arrays)
- [x] Array basic methods (`push`, `pop`, `shift`, `unshift`)
- [x] Array advanced methods (`map`, `filter`, `reduce`, `find`, `some`, `every`, `sort`)

**Objects**
- [x] Objects (create, properties, methods, nested objects)
- [x] Array of objects
- [x] Objects vs Arrays

**Operators & ES6 Features**
- [x] Spread & Rest operators
- [x] De-structuring (arrays & objects)


#### Level 3: Deeper Understanding (Intermediate)

**Scope & Execution**
- [x] Scope (block, function, global)
- [x] Hoisting
- [x] Temporal Dead Zone (TDZ)

**Special Concepts**
- [x] Closures
- [x] Pass by value vs Pass by reference
- [x] Shallow copy vs Deep copy

**Math & Numbers**
- [x] Numbers: floating point quirks, Special numbers - `NaN`, `Infinity`
- [x] Math functions (`Math.random`, `Math.floor`, etc.)

#### **Level 4: Asynchronous & Advanced JS**

**Callbacks & Asynchronous JS**
- [x] Event loop & call stack
- [x] Callbacks
- [x] Promises (`then`, `catch`)
- [x] Async/Await

**Error Handling**
- [x] Error handling (`try...catch`, custom errors)

**Advanced Array Usage**
- [x] Higher-order functions & array callbacks
- [x] Functional programming patterns

**This & Prototypes**
- [x] The `this` keyword (binding rules)
- [x] Prototypes & prototypal inheritance
- [x] Classes (`class`, `extends`, `super`)

#### Level 5: Browser & Environment
**DOM Manipulation**
- [x] DOM manipulation (select, update, remove elements)
- [x] Event listeners & event delegation

**Browser APIs**
- [x] Fetch API (GET/POST requests, JSON handling)
- [x] LocalStorage & SessionStorage
- [x] Cookies basics

**RegExp**
- [ ] Regular Expressions (RegExp)
- [x] Common use cases (validation, searching, replacing)

**Performance**
- [x] Performance optimization (debouncing, throttling)
- [x] Memory management basics

#### Level 6: Becoming Pro
**Modular JavaScript**
- [ ] ES6 Modules (`import`, `export`)
- [ ] CommonJS (Node.js basics)

**Design Patterns**
- [x] Module, Factory, Singleton, Observer

**Testing**
- [ ] Unit testing (Jest, Mocha, etc.)
- [ ] Debugging skills (DevTools, breakpoints)

**Modern JS & Beyond**
- [ ] Modern ES features (optional chaining, nullish coalescing, async generators)
- [ ] TypeScript basics
- [ ] Tooling (Babel, Webpack, ESLint, Prettier)

**Real-World Pro Skills**
- [ ] Working with APIs (REST, GraphQL)
- [ ] Security basics (XSS, CSRF)
- [ ] Service workers / Progressive Web Apps
- [ ] WebSockets (real-time apps)
