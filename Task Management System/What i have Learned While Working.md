### Icons in Webpage:
For React projects, the most popular option is **React Icons** — it gives you access to thousands of icons from multiple libraries in one package.

```JavaScript
npm install react-icons
```

install the react-icons using the above.

- To control the icons we need to use `font-size` -- Because the icons are similar to text.
- To control the background color  we can use `background-color` and for controlling the color of the icon we can use `color`. similar to text
